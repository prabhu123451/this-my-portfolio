PRABHU A - PORTFOLIO
====================

Folder structure
  index.html        -> page structure
  css/style.css     -> all styles
  js/script.js      -> all scripts (animations, orbit icons, form, routing)
  images/           -> all pictures
      profile.png                  (hero + summary photo)
      icons/                       (orbiting Figma / Illustrator / Photoshop logos - included)
      tools/                       (photoshop, illustrator, figma, canva logos)
      work/                        (graphic-design-cover, ui-ux-cover)
      graphic/                     (social-1..4, ad-1..4, product-1..4, brand-1)
      growplant/                   (cover + screen-1..8)
  copy-images.bat   -> Windows helper: copies your images from Downloads into the images folder

STEP 1 - Add your images
  Double-click copy-images.bat. It copies your files from C:\Users\<you>\Downloads
  into the correct images sub-folders with the right names.
  Any file it prints as MISSING must be copied into the images folder by hand
  (use the file name shown in the list above).

STEP 2 - Set your links (open index.html in a text editor, search for YOUR-USERNAME)
  LinkedIn : https://www.linkedin.com/in/YOUR-USERNAME
  Behance  : https://www.behance.net/YOUR-USERNAME

STEP 3 - Contact form
  Messages go to prabhusmart2005@gmail.com through FormSubmit.
  The first time someone submits the form, FormSubmit sends an activation email
  to that address - click the confirm link once. The form works best when the site
  is hosted online (Netlify, GitHub Pages, Vercel), not opened as a local file.

STEP 4 - Publish
  Upload the whole folder (keep the structure) to Netlify / GitHub Pages / Vercel.
